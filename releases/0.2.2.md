Exported HTML pages now keep some of what makes a Maru document useful: you can answer the questions, read chart values, and browse database views, all inside the exported file.

### New
- **Questions you can answer** — in an exported page, click an option to see whether it is right, the explanation for that option and the answer; "Try Again" clears it. Free-text questions have "Show Answer".
- **Chart values on hover** — exported charts show the same tooltip and crosshair as in the app (up to 1,000 points per chart).
- **Views you can browse** — exported database views carry their rows (up to 200 per preset, 1,000 per document), with the preset chips and "Show More" working in the file.
- The export writes one small script, `maru.export.js`, next to the pages. It makes no network requests; delete it and the pages read as before, without the interactions.

### Improved
- Agents using the Maru plugin now write what they find back into the document their search led them to, and date open-ended lists ("found as of …") instead of closing them.

### Fixed
- On networks that inspect TLS with their own certificate (company proxies, ZTNA), the `maru` command line now trusts the certificates in your Mac's keychain, so sending feedback and semantic search work there too.
- Settings rows and the "Mark All" button in Suggestions are vertically aligned again.
- Settings → Phone shows the relay address phones actually use.
