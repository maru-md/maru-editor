KMX is now **Maru**. This release renames everything, makes English the default language (Korean is still there), and lets you send us feedback without leaving the app.

### New
- **The name Maru** — a new app name, a new icon and a new home at https://maru.md.
- **English and Korean** — the app starts in English. Switch in Settings → Appearance → Language; the change applies at once.
- **Feedback from the app** — Settings → Feedback sends a bug report or an idea straight to us. You see exactly what will be sent before you send it, and your documents are never attached.
- **Update checks** — Maru tells you when a new version is out (Settings → Version & Updates). Updates install only when you click.
- **A new iPhone app** — the iPhone companion is now called Maru too.

### Improved
- Agent tools have clearer names: `list_documents`, `read_document`, `write_document`, `search_documents` and so on. The Claude Code plugin is now `maru@maru-md`.
- The command-line tool, its help and all agent-facing text are in English. Agents still answer in the language you write in.
- Public bug reports and ideas now have a home: https://github.com/maru-md/maru-editor/issues

### Notes
- **Your data moves** from `~/.kmx` to `~/.maru`, and the database file from `kmx.db` to `maru.db`. If you used KMX, follow "Coming from KMX" in the install guide before opening Maru.
- Links that start with `kmx:` no longer open the app; links inside your documents are converted automatically.
- **Pair your iPhone again** — install the new Maru iPhone app and pair it from Settings → Phone Pairing. The old KMX app stops connecting.
- Reinstall the Claude Code plugin from Settings → Maru Plugin so your agents see the new tool names.
- Version 0.1.0 cannot update itself — install 0.2.0 by hand once (write to hello@maru.md if you need the installer). From 0.2.0 on, Maru updates from inside the app.
