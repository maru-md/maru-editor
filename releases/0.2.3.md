The tools Maru gives your agents (the MCP server `editor`) were reworked after two agents reviewed them and a fresh agent tested every tool twice. Agents now edit long documents a block at a time, page through large lists, and always know when a document is read-only, in the Trash, or someone else's.

### New
- **Edit one block** — `edit_block` replaces, inserts after, or deletes a single block, so an agent no longer sends a whole long document back to change one line. Every write now returns the new version, so an agent can make several edits in a row without reading again.
- **Outline and partial reads** — `read_document` with `outline` gives the heading tree with block ids and sizes; reading part of a document also gives its version and can take a lock.
- **Find your way around** — `list_spaces` (spaces and folders with document counts), paging and totals on `list_documents`, comments and proposals; search can filter by folder or tag and group hits by document.
- **Data sources** — `list_sources` shows the database and document sources with their fields, and `query_source` previews rows without writing a view first.
- **Housekeeping** — agents can rename documents (with a note when it is someone else's, and never onto a title already taken) and move documents they wrote alone to the Trash. `read_proposal` shows what a proposal changes.
- **A guide for every client** — `read_guide` returns the writing guide (charts, questions, views, tags), so agents in clients without the Maru skill can read it too.

### Improved
- Reading a document now shows its tags and frontmatter; change the `tags` list to change them.
- Agents always pass the version they read when they edit, so they can't overwrite a newer edit by accident.
- Connected documents say they are read-only and where they come from when you read them, not only when a write fails.
- Each agent's edits, comments and locks carry a name you can find, instead of "claude".
- Error messages say what to do next (read again, which fields exist, which spaces exist, where to edit a connected document).

### Fixed
- A document moved to the Trash can no longer be edited by agents, the command line or the phone. If it was open in the app, your unsaved edits are kept as a draft and come back when you restore it.
- Renaming a document also fixes links in documents that are in the Trash, so they still work after a restore.
- A typo in a space name no longer creates a new space.
