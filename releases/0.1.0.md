The first build of Maru that is signed with a Developer ID and notarized by Apple, so it opens like any other Mac app.

### New
- A disk image (`Maru-0.1.0.dmg`) — drag Maru to your Applications folder.
- Block-based documents with spaces, folders, tags, comments, charts, questions and live views.
- A built-in AI agent that reads and edits the document you are looking at.
- The `maru` command-line tool and an MCP server, so Claude Code and other agents can work in your documents.

### Notes
- Apple Silicon Macs (M1 or later) only.
