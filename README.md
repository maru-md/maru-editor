# Maru Editor

**Maru** is a knowledge editor that people and AI agents write in together — a block-based document app for Apple Silicon Macs, with an iPhone companion and an MCP server so your agents can read and write the same documents.

- Website: https://maru.md
- Contact: hello@maru.md

This repository is Maru's **public issue tracker and release notes**. The source code lives in a private repository.

## Report a bug or suggest an idea

[Open an issue](https://github.com/maru-md/maru-editor/issues/new/choose) and pick **Bug report** or **Idea**.

Issues here are public — please don't paste private document contents, keys or personal data.
If your report needs private details, send it from inside the app (Settings → Feedback) instead; those reports go to us directly and are not published.

Release notes are published under [Releases](https://github.com/maru-md/maru-editor/releases).
